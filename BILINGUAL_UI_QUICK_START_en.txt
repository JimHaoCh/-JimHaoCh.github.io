NE-501 v1.4.0 quick start

1 Connect & map: connect real pumps or the mock controller, select pumps used in this experiment, and verify physical addresses and inlet paths.
2 Syringes: enter actual inside diameters in mm. New plans start blank. Entered values and current device read-backs have separate labels.
3 Tubing: confirm preparation, explicitly skip this time, or set up finite priming with a positive rate and volume. Write and start priming separately.
4 Operation: choose manual delivery or timeline simulation. Set full units, direction and continuous/target mode. Startup Prime remains available under Advanced.
5 Review & start: inspect the listed targets and volume stages. Write/read back manual settings, then explicitly start the reviewed pumps. Timeline playback is simulation only.

Review buttons open the summary without moving pumps. Stop all remains in the top bar, cancels simulation and sends STOP to all configured addresses. Confirm each pump response. Warning windows leave the main window accessible.

Shared syringe plans, selected tracks, fluid/inlet names and timeline blocks are saved in JSON. Manual delivery values and user/device confirmations belong to the current session. Imported files require a new preparation check; they never supply device read-back proof.

Existing timeline drag, resize, split, copy, snapping, zoom, shortcuts, undo/redo, JSON, language and UI-size controls remain available. Unused tracks retain blocks and are skipped during simulation.

Windows x64 and Windows 11 ARM64 share the installer. See BILINGUAL_MANUAL_UI_v1.4.0.md and UI_REVIEW_v1.4.0.md for details and validation limits. Actual flow, tubing behavior and pump synchronization need hardware measurements.
