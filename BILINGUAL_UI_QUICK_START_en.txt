NE-501 v1.4.2 quick start

Choose Manual Control or Timeline Editor above the step bar.
Manual Control: connect/map > syringes > optional manual priming > manual settings > review/start.
Timeline Editor: pumps/paths > syringes > timeline editor > check/preview.

Connection category and editing function are separate. Demo mode connects virtual pumps. Offline planning has no controller connection. Real pump connection identifies an open real controller connection; individual responses establish device status. Loading an example workflow changes planning data and leaves the controller category unchanged.

Timeline playback is called Flow preview and sends no pump start commands. Author any initial preparation as timeline blocks; all included blocks contribute to the totals. Independent priming and device program writes remain in Manual Control. A blank or unsaved filename is Untitled workflow.

A rewrite of DIA or program settings invalidates the previous program proof before dispatch. Review manual targets and volume stages, write/read back settings, then explicitly start the listed pumps. Immediate manual priming and optional startup Prime have different execution times.

Unapplied timeline drafts survive switching to manual control. Single-pump review guidance follows the listed targets. Editor and review preview share running/pending-command locks. Disconnecting without confirming STOP retains an unconfirmed-stop indicator.

Stop all stops the preview and sends STOP to every configured address. An active configuration batch finishes before the queued STOP worker; command-level cancellation is a recommended follow-up. The demo controller acknowledges commands and does not yet advance finite delivery or Prime phases by elapsed time.

See BILINGUAL_MANUAL_UI_v1.4.2.md and UI_REVIEW_v1.4.2.md. Windows x64 and Windows 11 ARM64 share the installer. Actual delivery, tubing and synchronization require hardware measurements.
