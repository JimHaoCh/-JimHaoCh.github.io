NE-501 v1.4.0 — 共用準備流程與介面重整

Windows x64 / Windows 11 ARM64 共用安裝檔。

主要更新
1. 五步共用流程：連線對應、針筒設定、管路準備、操作設定、檢查啟動。
2. 針筒內徑以淺底深字、大數值、固定 mm 與內側直徑示意圖呈現。
3. 新實驗內徑空白；本次使用的幫浦、流體與入口名稱、內徑跨模式共用。
4. 已輸入、設備回讀、使用者確認及模擬檢查分別標示。
5. 手動設定串接內徑與輸送程式的寫入／回讀；核對摘要後另按啟動。
6. 管路排氣／預充使用獨立的定量操作；啟動前 Prime 保留五檔。
7. 單位切換換算數值，超出欄位範圍時提示；正式寫入後核對設備量化結果。
8. 全域停止處理模擬與實機；錯誤提示保留停止操作入口。
9. 保留四台獨立、群組、定量／連續、方向、時間軌工具、雙語、縮放及診斷。

初次使用：從「1 連線對應」選本次使用的幫浦，按底部提示完成準備。
本次只用兩台時，以這兩台計算進度。示範流程須明確載入，10 mm 是示範值。

手動控制及定量管路準備會操作連線設備；流程播放維持模擬。
實際流量、管路與多幫浦時序仍待實機量測。0.1 秒為編輯刻度。
JSON 保存共同準備及時間軌；手動輸送數值與確認狀態屬目前工作階段。

完整操作見 BILINGUAL_MANUAL_UI_v1.4.0.md，驗證與限制見 UI_REVIEW_v1.4.0.md。
