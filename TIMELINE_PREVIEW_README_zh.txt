NE-501 多幫浦控制介面預覽 v1.3.0

以 v1.2.0 為基礎更新手動操作路徑：
- 連線並偵測：連線成功後自動偵測幫浦。
- 四步提示：確認內徑、設定輸送、套用回讀、啟動。
- 設定區固定顯示目前幫浦與位址；套用、啟動、停止集中於同一操作列。
- 已確認內徑收合；完成回讀後，黃色提示移至啟動。
- 群組列出就緒台數、待處理原因與「前往處理」，各按鈕顯示作用台數。
- 輸入不完整時顯示欄位提示；修改內徑導致群組勾選清除時顯示原因。
- 設定區加寬；小視窗／大字體採精簡卡片，保留四台停止入口。
- 上次設備回報以時間與秒數呈現，必要操作另有明確提示。
- 繁體中文／English 切換保留各台設定、草稿及勾選。

手動頁會操作已連線的實體設備。四軌流程編輯、拖曳、分割、復原／重做、儲存及播放沿用；時間軌播放維持模擬。

安裝檔 NE501_UI_v1.3.0_Setup.exe 支援 Windows x64／ARM64，無須另裝 Python。安裝程式延續 v1.2.0 的應用程式位置與使用者設定，並與早期 v1.0.1 安裝位置分開。

發布前執行模擬回歸、雙語及縮放畫面檢查，以及兩種 Windows 架構的封裝、安裝和解除安裝測試。實際四幫浦的時序、流量與同步誤差尚待實機量測；0.1 秒為時間軌編輯刻度。
