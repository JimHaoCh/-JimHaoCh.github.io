NE-501 v1.4.1 — 手動／流程模式分流

Windows x64 / Windows 11 ARM64 共用安裝檔。

先從步驟列上方選模式。
手動：1 連線對應 → 2 針筒設定 → 3 管路／排氣 → 4 手動設定 → 5 檢查啟動。
流程：1 幫浦流路 → 2 針筒設定 → 3 流程編輯 → 4 檢查模擬。

本版更新
1. 獨立定量排氣／預充只在手動模式操作。流程的前段準備由時間軸區塊安排。
2. 流程摘要包含全部啟用區塊的推進／抽取量，移除手動排氣及啟動前預送欄位。
3. 改寫內徑或程序前，先撤銷該泵的舊程序驗證；失敗或逾時後需重新寫入並回讀。
4. 流程區塊與總長度草稿在切換到手動後保留。共用資料更新會要求重新檢查流程。
5. 單台核對的提示依表列幫浦判斷；切回全部範圍時再檢查本次全部幫浦。
6. 模擬編輯器、摘要與直接播放使用相同的設備忙碌／待停止條件。
7. 保留四台獨立及群組、連續／定量、方向、五檔啟動前Prime、拖曳／分割／復原、雙語及縮放。

裝好針筒與微流道後，手動模式須核對位址／入口、針筒固定、接頭與出口／閥路，填入實際內徑mm。
立即排氣在第3步獨立啟動；啟動前預送（Prime）隨正式程序啟動。請分別核對兩項設定量。
正式程序先寫入並回讀，再從摘要啟動表列幫浦。新實驗內徑空白，10mm示範值須明確載入。

手動控制與獨立排氣會操作已連線設備；流程播放為模擬。
實際流量、管路行為與多泵同步仍待實機量測。0.1秒為編輯刻度。
JSON保存共用準備及時間軸；手動數值、使用者確認與設備回讀屬目前工作階段。
全域停止會停止模擬，並對全部已設定位址執行停止流程；停止結果逐台確認。
