NE-501 多幫浦控制介面預覽 v1.3.1

本版補入流程針筒設定，並修正原始碼審查確認的數值與資料問題。

流程操作：
1. 按上方「針筒」，設定各使用中幫浦的實際內徑；也可帶入手動頁已確認內徑。
2. 區塊仍以體積流速輸入；設定區列出推桿速度換算、規劃／設備內徑及指令流速。
3. 修改內徑後須重新檢查。流程檔保存各台內徑；舊檔缺少內徑時要求補入。
4. 時間軌播放維持模擬。針筒規劃視窗只編輯資料。

重要修正：
- 修正 1000 被格式化成 1、1200 變成 12 的四位整數尾零錯誤。
- 收緊低流速、小體積及內徑的讀回比對；支援 4.699 mm 等可表示的三位小數內徑。
- 模擬控制器與實機共用設定和讀回程式。
- 修正儲存後重新開同檔的舊快取、極大數值解析及同時啟動覆寫紀錄。
- 拒絕設定檔小數／布林／重複位址，顯示錯誤後停止啟動。

手動頁延續內徑、輸送、回讀、啟動四步提示與同區套用／啟動／停止，並保留群組控制、Prime 五檔及中英文切換。

NE501_UI_v1.3.1_Setup.exe 為 Windows x64／Windows 11 ARM64 通用安裝檔，免另裝 Python。延續既有 UI Preview 安裝位置與使用者設定。

發布前須通過原始碼回歸及兩種 Windows 架構的封裝、安裝、版本與模擬操作測試。實際幫浦流量及時序仍待實機驗證。請參閱 BILINGUAL_MANUAL_UI_v1.3.1.md、SOURCE_AUDIT_v1.3.1.md 及 DISCLAIMER.txt。
