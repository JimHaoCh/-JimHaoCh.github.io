NE-501 v1.5.2 — 同頁手動操作台

Windows x64 / Windows 11 ARM64 共用安裝檔，更新既有 UI Preview。

手動路徑
1 連線對應：連線偵測並選本次幫浦，直接前往針筒設定，無額外核對勾選。
2 針筒設定：填入實際針筒內徑 d（mm）；已移除固定／管路確認選單。
3 手動操作台：設定正式輸送，寫入並回讀，在各台卡片啟動、續跑或停止。

操作台
各台卡片固定保留啟動／停止；右側編輯所選幫浦，底部亦有寫入、啟動與停止。
P1 運轉時仍能設定及操作 P2。編輯對象與群組勾選分別保存。
針筒內徑僅在步驟 2 輸入；操作台顯示摘要，修改入口返回步驟 2。
空白欄位點入即隱藏提示，可直接鍵入或貼上數字；兩種模式共用此操作。
支援 Enter／Tab，以及直接滑鼠按寫入並回讀。
獨立預充停止後，可直接在操作台按正式啟動，無須額外管路確認。

排氣／預充
共用一套設定，支援五段速度及自訂流速、方向與定量體積。
先按「寫入並回讀」，再另按「僅啟動排氣」。
「預充完成後接續正式輸送」預設關閉；勾選後另按預充啟動才執行。
正式啟動及續跑直接進入正式區段。

停止與續跑
單台／群組停止：確認馬達停止，保留原廠暫停進度；繼續輸送接續剩餘量。
定量暫停另有「重新完整一劑」，重設並輸送完整設定量。
停止所有幫浦：向全部設定位址停止並結束程序，逐台確認結果。
停止要求取消尚未送出的設定；目前通訊回應後優先處理停止。
停止結果依設備回報確認；逾時、重新偵測及斷線均保留停止未確認清單。
狀態查詢逾時後仍嘗試 STOP；指令紀錄寫入失敗不會阻擋設備狀態更新。

流程路徑
1 幫浦流路 → 2 針筒設定 → 3 流程編輯 → 4 檢查預覽。
前段預充安排為時間軸區塊，全部啟用區塊計入總量。
流程預覽不傳送幫浦啟動指令。

名稱與資料
手動控制／流程編輯是功能分頁，示範模式指虛擬幫浦連線。
離線規劃、實機連線各有標示；範例載入保留連線類型，取消後保留模式與草稿。
示範控制器依時間推進定量、預充與接續輸送，支援保留進度續跑。
JSON 格式及流程編輯能力沿用前版；設備驗證屬本次工作階段。
