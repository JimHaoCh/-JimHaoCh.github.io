NE-501 v1.4.2 — 功能、示範模式與流程預覽分開命名

Windows x64 / Windows 11 ARM64 共用安裝檔。

新版名稱
手動控制：操作已連線的實體或虛擬幫浦。
流程編輯：編排時間軸，檢查流程與預覽。
示範模式：連接虛擬幫浦控制器，供介面及指令操作練習。
離線規劃：沒有設備連線，仍可編輯及預覽流程。
實機連線：已開啟實體設備連線；實際幫浦狀態另以各台回報確認。
流程預覽：計算並播放時間軸；不傳送幫浦啟動指令。
範例流程：內建的資料範本，載入不會切換連線類型。

操作路徑
手動：1連線對應 → 2針筒設定 → 3管路／排氣 → 4手動設定 → 5檢查啟動。
流程：1幫浦流路 → 2針筒設定 → 3流程編輯 → 4檢查預覽。

本版顯示調整
1. 流程分頁移除「模擬」括號；示範模式僅標示虛擬控制器連線。
2. 播放與每軌狀態統一稱為流程預覽；頁面持續標示不傳送幫浦啟動指令。
3. 新空白流程顯示「未命名流程」；內建資料入口稱「載入範例流程」。
4. 斷線後若仍有運轉或停止尚未確認的紀錄，狀態列會保留「停止未確認」。

沿用的設定保護
獨立排氣限手動模式；流程前段準備直接安排於時間軸。
內徑或程序寫入前撤銷舊驗證，完整回讀成功後再允許啟動。
保留跨模式草稿、單泵核對提示、群組、五檔Prime、進階時間軸工具、雙語與縮放。

注意操作範圍
示範控制器目前以指令回覆為主，定量輸送／Prime階段尚未依時間自動完成。
流程預覽使用設定值估算輸送量；實際送液與設備同步仍需實機量測。
全域停止仍須等待當前程序批次結束；已列為後續改善優先項目。
